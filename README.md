## 🗺️ If You're Starting From Zero

Follow this order:

**1. Mathematics → 2. Programming → 3. Statistics → 4. Financial Markets → 5. Quant Finance → 6. Trading/Research → 7. ML → 8. Interviews**

Don't try to finish every resource. Pick **one good resource per topic and start building.**

## 📈 Trading

These are the books I found particularly useful for developing my understanding of **entries, exits, market structure, trade selection and strategy development**:

* *Targeting Profitable Entry & Exit Points* — Alan Farley
* *The Master Swing Trader* — Alan Farley
* *The Four Cardinal Principles of Trading* — Bruce Babcock
* *Advanced Swing Trading* — John Crane
* *Dynamic Trading* — Robert Miner
* *High Probability Trading Strategies* — Robert Miner
* *Secrets for Profiting in Bull and Bear Markets* — Stan Weinstein
* *Swing Trading for Dummies*

> **Important:** Don't optimize for win rate alone. Evaluate **expectancy, drawdown, risk/reward, transaction costs and robustness**.

## 🛠️ What To Build

Don't just consume resources.

Build:

* 📊 Backtesting engine
* 📈 Momentum / mean-reversion strategy
* 🔄 Pairs trading strategy
* 🧮 Options pricing model
* 📉 Volatility forecasting model
* 💰 Portfolio optimizer
* 📖 Limit order book simulator
* 🤖 ML-based trading strategy

### The loop

**Learn → Implement → Backtest → Validate → Improve**
